# Volley.ru HD & NoAds

Юзерскрипт для [volley.ru](https://volley.ru): HD-качество (1080p) и удаление рекламы.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) (или Violentmonkey).
2. **Только Chrome:** `chrome://extensions/` → «Подробнее» у Tampermonkey → включите **«Разрешить пользовательские скрипты»**.
3. Откройте ссылку на скрипт: https://github.com/C8QKyBA26jnVY4/Volley.ru-HD-NoAds/raw/refs/heads/main/volley-hd-noads.user.js
4. Нажмите «Установить» на открывшейся странице Tampermonkey.
5. Откройте volley.ru и обновите страницу (Ctrl+F5).

> **Если ссылка не открывается:** GitHub может быть недоступен из-за блокировок, и для первой установки, возможно, понадобится VPN. После установки скрипт работает без VPN.
> Запасной вариант: скопируйте содержимое `volley-hd-noads.user.js` из репозитория, в Tampermonkey нажмите «Создать скрипт», вставьте код и сохраните (Ctrl+S).

## Не работает?

Откройте консоль (F12): должна быть строка `[VolleyFix] Запуск полной очистки...`. Если её нет, проверьте, что скрипт включён в Tampermonkey и (в Chrome) включён «Разрешить пользовательские скрипты».

## Зачем это

**Чем больше зрителей, тем больше волейбола.** Скрипт нужен, чтобы матч можно было спокойно посмотреть без рекламы и в хорошем качестве. Понравилось — позовите друга, сходите на игру своего города или купите билет на живой матч.
